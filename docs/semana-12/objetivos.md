# Semana 12 · Pruebas unitarias

## Resultado de aprendizaje

Al finalizar la semana podrás comprobar reglas de negocio y controladores de forma aislada con Jest, diseñando casos de prueba que comuniquen el comportamiento esperado de CourseHub API.

## Entregable semanal

El proyecto tendrá pruebas unitarias para, al menos, un caso de uso con autorización de propiedad y un controlador. Las pruebas usarán dobles controlados en lugar de una base de datos real.

## Límites de esta semana

- Sí: Jest, estructura Arrange-Act-Assert, mocks y pruebas de servicios, casos de uso y controladores.
- Sí: casos de éxito, límites y errores esperados.
- No todavía: pruebas e2e, base de datos de pruebas ni automatización CI/CD; esos temas pertenecen a la Semana 13.

Una prueba unitaria no demuestra que PostgreSQL o HTTP funcionen juntos. Demuestra, de manera rápida y repetible, que una unidad de código cumple una regla concreta.
