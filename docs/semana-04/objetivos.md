# Semana 4 · Persistencia con PostgreSQL y TypeORM

## Resultado de aprendizaje

Al finalizar la semana podrás configurar una conexión de desarrollo, modelar un curso como entidad y sustituir el arreglo temporal por un repositorio persistente.

## Entregable semanal

CourseHub API guardará cursos en PostgreSQL mediante TypeORM. La configuración sensible vivirá en variables de entorno y el CRUD de las semanas anteriores seguirá respondiendo con el mismo contrato HTTP.

## Límites de esta semana

- Sí: PostgreSQL local, configuración por entorno, entidad `Course`, repositorio TypeORM y CRUD persistente.
- No todavía: autenticación, relaciones complejas, migraciones de producción o despliegue.
