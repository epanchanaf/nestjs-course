# Curso de NestJS

Este curso usa **CourseHub API** como proyecto transversal: una API para explorar cursos. El producto crecerá de forma gradual; cada semana añade capacidades justificadas por los fundamentos estudiados.

En la Semana 1 aprenderás a crear una aplicación NestJS, entender su estructura y responder desde un controlador. Aún no construiremos un CRUD completo, DTOs, validaciones ni conexión a base de datos.

## Dinámica de cada sesión (2 horas)

| Bloque | Tiempo | Propósito |
| --- | ---: | --- |
| Teoría en diapositivas | 24 min · 20% | Construir un modelo mental desde la documentación oficial. |
| Ejemplo guiado | 36 min · 30% | Leer, ejecutar y explicar el código línea por línea. |
| Proyecto integrador | 60 min · 50% | Aplicar el aprendizaje en el repositorio personal. |
