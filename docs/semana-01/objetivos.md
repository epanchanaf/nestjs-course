# Semana 1 · Fundamentos de NestJS

## Resultado de aprendizaje

Al finalizar la semana podrás crear y ejecutar una aplicación NestJS, identificar el papel de módulo, controlador y servicio, exponer una respuesta HTTP simple para CourseHub API y explicar cómo el modelo asíncrono de Node.js permite atender operaciones de servidor sin bloquear el flujo principal.

## Entregable semanal

Cada estudiante tendrá un repositorio **público** de GitHub llamado `coursehub-api`. Allí publicará todo el código desarrollado durante el curso. El primer entregable es una aplicación arrancable con la ruta `GET /` y una ruta de bienvenida para CourseHub API.

## Límites de esta semana

- Sí: CLI, estructura inicial, módulos, controladores, servicios e inyección de dependencias.
- Sí: modelo asíncrono de Node.js, *event loop* y criterio básico para evitar operaciones bloqueantes.
- No todavía: CRUD completo, DTOs, validación, autenticación, base de datos o persistencia.
